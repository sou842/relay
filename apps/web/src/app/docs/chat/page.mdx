# Using the chat

Open an instance and click **Open chats**. The layout follows WhatsApp Web:
chat list on the left, the conversation on the right.

## What you can do

- **Start a chat**: the new-chat button checks the number is on WhatsApp first.
  Use the full number with country code.
- **Send** text, emoji, photos, videos, documents, voice notes, contacts,
  locations and polls. Drag a file onto the conversation to attach it.
- **Reply, react, edit, delete for everyone, forward, copy**: hover a message
  and open its menu.
- **See status ticks**: one grey tick sent, two grey delivered, two blue read.
- **Live updates**: new messages, ticks, typing and online status arrive
  instantly without refreshing.

## What history is shown

Relay shows messages sent or received **while the gateway has been running
since the instance was linked**. Older chats from your phone are not imported.
Contact names appear once a contact has messaged you; until then you see their
number.
