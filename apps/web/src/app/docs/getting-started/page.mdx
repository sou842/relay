# Getting started

You need **Node.js 24 or newer** and a **MongoDB** database (a free Atlas
cluster works).

## 1. Install

From the repository root:

```bash
npm install
```

This installs both workspaces: `apps/gateway` and `apps/web`.

## 2. Configure the gateway

Create `apps/gateway/.env`:

```bash
# Long random string; the web app uses it to create and delete instances.
GATEWAY_ADMIN_KEY=change-me-to-a-long-random-string
GATEWAY_PORT=7700
# MongoDB for all gateway state (sessions, history, queue, media).
# The same cluster as the web app is fine; it uses its own database.
GATEWAY_MONGODB_URI=mongodb+srv://user:password@cluster.mongodb.net
GATEWAY_MONGODB_DB=relay_gateway
# Optional: public base URL put into media download links (e.g. your tunnel URL)
# GATEWAY_PUBLIC_URL=https://gateway.example.com
```

Generate a key with:

```bash
node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"
```

## 3. Configure the web app

Create `apps/web/.env.local`:

```bash
MONGODB_URI=mongodb+srv://USER:PASSWORD@cluster.example.mongodb.net/?retryWrites=true&w=majority
MONGODB_DB=relay

BETTER_AUTH_SECRET=another-long-random-string
BETTER_AUTH_URL=http://localhost:3000

GATEWAY_URL=http://127.0.0.1:7700
GATEWAY_ADMIN_KEY=the-same-key-as-the-gateway
```

> Both `.env` files are git-ignored. Never commit them. If credentials leak,
> rotate the MongoDB password and generate new keys.

## 4. Run

Open two terminals at the repository root:

```bash
npm run gateway   # http://127.0.0.1:7700
npm run web       # http://localhost:3000
```

## 5. Create your account and an instance

1. Open [http://localhost:3000/sign-up](/sign-up) and create an account.
2. In the dashboard, click **New instance**, pick WhatsApp and give it a name.
3. Scan the QR code, as described in [Linking WhatsApp](/docs/linking).

That's it. Open **Open chats** to start messaging.
